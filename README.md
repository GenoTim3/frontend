# 📖 Mythical Tales — AI-Powered Children's Storybook

A kid-friendly web app where children pick a mythical creature, give it a name, and get a unique 5-page adventure story generated by Llama 3 running locally via Ollama.

## Prerequisites

- **Node.js** (v18+) — https://nodejs.org
- **Ollama** — https://ollama.com/download
- **Llama 3** model pulled in Ollama

## Setup

### 1. Install Ollama & pull Llama 3

```bash
# Install Ollama from https://ollama.com/download, then:
ollama pull llama3
```

### 2. Backend

```bash
cd backend
npm init -y
npm install express cors
```

Create `server.js` (or paste the provided code) in the `backend/` folder.

### 3. Frontend

```bash
cd frontend
npx create-react-app .
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p
```

Update `tailwind.config.js`:

```js
module.exports = {
  content: ["./src/**/*.{js,jsx}"],
  theme: { extend: {} },
  plugins: [],
};
```

Replace contents of `src/index.css` with:

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

Then add the component files into `src/components/` and the hook into `src/hooks/`.

## Running the App

You need **3 terminals**:

**Terminal 1 — Ollama:**
```bash
ollama serve
```

**Terminal 2 — Backend:**
```bash
cd backend
node server.js
# → 🐉 Story server running at http://localhost:3001
```

**Terminal 3 — Frontend:**
```bash
cd frontend
npm start
# → Opens http://localhost:3000
```

## How It Works

1. Child clicks "Start Your Adventure"
2. Picks a creature (Dragon, Griffin, Pegasus, Phoenix, Unicorn) or types a custom one
3. Names their creature
4. Frontend sends a request to the Express backend (`POST /api/story`)
5. Backend builds a kid-safe prompt and sends it to Ollama (Llama 3)
6. Llama 3 returns a 5-part JSON story
7. Frontend displays it as a colorful, slide-by-slide storybook

## API Endpoints

| Method | Endpoint        | Description                        |
|--------|-----------------|------------------------------------|
| POST   | `/api/story`    | Generate a story                   |
| GET    | `/api/health`   | Check Ollama connection & models   |

### POST /api/story

**Request:**
```json
{
  "creature": "Dragon",
  "creatureName": "Sparkle"
}
```

**Response:**
```json
{
  "slides": [
    "Once upon a time...",
    "One sunny morning...",
    "Deep in the forest...",
    "Together they...",
    "And they all lived... The End!"
  ]
}
```

## Troubleshooting

| Problem                          | Fix                                                  |
|----------------------------------|------------------------------------------------------|
| `Could not determine executable` | Make sure you're in the `frontend/` directory         |
| `Failed to generate story`       | Check that Ollama is running (`ollama serve`)         |
| `Cannot reach Ollama`            | Visit http://localhost:11434 to verify Ollama is up   |
| JSON parse errors                | The backend has fallback parsers — try regenerating   |
| Slow story generation            | Normal for Llama 3 on CPU. GPU speeds it up a lot.   |
